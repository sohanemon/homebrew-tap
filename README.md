# 🍺 homebrew-tap

Small tools, shipped fast.

## Install

```sh
brew tap sohanemon/tap
brew install --cask <tool>
```

Or in one go:

```sh
brew install --cask sohanemon/tap/<tool>
```

## Tools

| Tool | What it does |
|------|--------------|
| [git-outlet](https://github.com/sohanemon/git-outlet) | Publish selected files and folders from a private Git repo |
